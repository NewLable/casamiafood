Casa Mia CMS

Сайт обновляется из браузера. Одна кнопка «Сохранить изменения» — без VS Code и GitHub Desktop.

1. Первый запуск

  1. Откройте admin.html (лучше сохранить в закладки).
  2. Войдите по паролю.
  3. Вкладка «Настройки GitHub»: username, репозиторий, ветка main, токен.
  4. На чужом телефоне не ставьте «Запомнить этот компьютер».
  5. Должно появиться ✅ Подключено.
Токен: GitHub → Settings → Developer settings → Fine-grained tokens. Право Contents: Read and write только для этого репозитория.

2. Как изменить цену

  1. Админка → «Цены».
  2. Новая сумма.
  3. Зелёная кнопка внизу «Сохранить изменения».

3. Как добавить товар

  1. «Товары» → новый товар.
  2. Фото, название (4 языка), цена, категория.
  3. Сохранить изменения.

4. Как удалить товар

  1. Откройте карточку → «Удалить товар».
  2. Снова нажмите «Сохранить изменения».

5. Как изменить доставку

  1. «Настройки сайта» → Доставка.
  2. Районы, стоимость, время, оплата — на RU / UA / TR / EN.

6. Текст «О нас»

  1. «Настройки сайта» → О нас.
  2. Не копируйте русский текст в другие языки автоматически.

7. Как заменить фото

  1. Откройте товар → Заменить / перетащите файл.
  2. Картинка сама станет WebP шириной до 1200 px.

8. Язык на сайте

  1. В шапке сайта кнопки RU · UA · TR · EN.
  2. Если перевод пустой — показывается русский.

9. Что делает «Сохранить»

  1. JSON и фото записываются в GitHub.
  2. Создаётся commit с датой.
  3. GitHub Pages публикует сайт за 20–60 секунд.

11. Корзина и WhatsApp

  1. Админка → вкладка «Корзина»: минимальная сумма, бесплатная доставка, WhatsApp, Instagram.
  2. Приветствие заказа меняйте на RU / UA / TR / EN — список блюд подставится сам.
  3. У товара выберите тип количества: упаковка, штуки, килограммы или граммы.
  4. Если блюдо закончилось: снимите «В наличии» или включите «Скрыт» и сохраните.
Гость отправляет готовый текст в WhatsApp. Оплаты на сайте нет.

12. Сайт не обновился

  1. Подождите минуту и обновите страницу.
  2. Проверьте зелёный статус GitHub.
  3. Смотрите «Последние публикации».
  4. Если токен истёк — вставьте новый.
