Помощь владельцу

Короткие инструкции без программирования. Сайт обновляется кнопкой «Сохранить изменения» — VS Code и GitHub Desktop не нужны.

Открыть инструкцию отдельной страницей

1. Первый запуск — 1 минута

  1. Откройте casamiafood.vip/admin.html (сохраните в закладки).
  2. Введите пароль админки.
  3. Зайдите в «Настройки GitHub», вставьте токен один раз и нажмите «Сохранить подключение».
  4. Должно появиться: ✅ Подключено.

2. Как изменить цену — 20 секунд

  1. Вкладка «Цены».
  2. Впишите новую сумму.
  3. Нажмите зелёную кнопку внизу «Сохранить изменения».
  4. Подождите плашку «Изменения опубликованы».
Пока кнопка серая — менять было нечего. После правки цены она станет зелёной.

3. Как добавить товар — 30 секунд

  1. Вкладка «Товары» → «+ Новый товар».
  2. Загрузите фото (можно с телефона, перетащите в рамку).
  3. Заполните название хотя бы на русском, цену и категорию.
  4. Нажмите «Сохранить изменения» внизу страницы.

4. Как удалить товар

  1. Откройте карточку товара.
  2. Нажмите «Удалить товар» и подтвердите.
  3. Обязательно нажмите «Сохранить изменения» — иначе на сайте товар останется.

5. Как заменить фото

  1. Откройте товар.
  2. Нажмите «Заменить» или перетащите новое фото.
  3. Админка сама уменьшит картинку и сделает квадратную миниатюру.
  4. Сохраните изменения — фото уйдёт в GitHub вместе с меню.

6. Как сделать товар «Хитом недели»

  1. Откройте карточку товара.
  2. Включите галочку «Хит продаж».
  3. Сохраните. Товар появится в блоке хитов на главной.

7. Как изменить доставку

  1. Вкладка «Настройки сайта» → блок «Доставка».
  2. Заголовок, описание, районы, стоимость, время и оплата — каждое поле на 4 языках.
  3. Сохраните изменения.

8. Как изменить текст «О нас»

  1. Вкладка «Настройки сайта» → блок «О нас».
  2. Заголовок и описание на RU / UA / TR / EN.
  3. Не копируйте русский текст в другие языки автоматически — напишите перевод или оставьте пустым.

9. Как переключить язык на сайте

  1. На сайте в шапке кнопки RU · UA · TR · EN.
  2. Выбор запоминается в браузере гостя.
Если перевод пустой, посетитель увидит русский текст. Это нормально. Лучше заполнить все 4 языка, когда будет время.

10. Что происходит после «Сохранить»

  1. Админка записывает JSON и фото в GitHub.
  2. Создаётся commit с датой и временем.
  3. GitHub Pages сам публикует сайт — обычно 20–60 секунд.
  4. Вы увидите: ✅ Изменения опубликованы на сайте.

11. Google и Яндекс Карты

  1. Зарегистрируйте компанию в Google Business Profile (Google Карты) на адрес/зону доставки в Анталии.
  2. Добавьте профиль в Яндекс Бизнес — так вас найдут из навигатора.
  3. На сайте уже есть ссылки на поиск «Casa Mia Antalya». После регистрации карточки они начнут приводить заказы сами.
Для локального бизнеса в Анталии карты часто дают больше заявок, чем SEO самого сайта.

Что делать, если сайт не обновился

  1. Подождите минуту и обновите страницу сайта без кэша.
  2. Проверьте, что GitHub подключён (зелёный статус).
  3. Откройте «Последние публикации» — там должно быть свежее сообщение.
  4. Если токен истёк — вставьте новый в «Настройки GitHub».
