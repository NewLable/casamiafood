# Casa Mia Admin

Пароль: см. README (выдан при создании проекта).

## Как пользоваться

1. Откройте `/admin.html`
2. Войдите по паролю
3. Правите товары / цены / категории / контакты
4. Нажмите **Скачать JSON**
5. Замените файлы в папке `data/` скачанными
6. Если меняли фото — положите файл в `images/products/`
7. Закоммитьте и сделайте push → GitHub Pages обновит сайт за 20–60 сек

## Языки (RU / UA / TR / EN)

У каждого текстового поля в админке — **4 строки**: RU, UA, TR, EN.

- Товар: название, описание, состав, как готовить, с чем подавать  
- Категории: название  
- Контакты / тексты: доставка, оплата, слоган, блок «О нас»  

Цены, вес, WhatsApp и Instagram — без языков (общие).

Если оставить UA/TR/EN пустыми, на сайте покажется русский (fallback на RU). Лучше заполнять все 4.

## Важно

- Ссылка на админку: `https://casamiafood.vip/admin.html` (в меню сайта её нет — сохраните в закладках).
- Админка **не пишет на сервер** сама — только готовит JSON в браузере.
- **Фото с телефона в админке сейчас не загружаются на сайт.** Выбор файла только подставляет путь; картинку нужно добавить в `images/products/` и закоммитить (или прислать мне — положу в git).
- Пароль хранится как SHA-256 хеш в `settings.json` (базовая защита «от случайных глаз», не банковский уровень).
