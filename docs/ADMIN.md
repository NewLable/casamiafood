# Casa Mia Admin

Пароль: см. README (выдан при создании проекта).

Актуальная инструкция для владельца встроена в админку: вкладка **📖 Помощь владельцу**.  
Дубли: [OWNER_GUIDE.md](OWNER_GUIDE.md), [owner-guide.html](../owner-guide.html).

## Как пользоваться

1. Откройте `/admin.html`
2. Войдите по паролю
3. Один раз подключите GitHub (вкладка «Настройки GitHub»)
4. Правите товары, цены, тексты, фото
5. Нажмите **💾 Сохранить изменения** внизу экрана

JSON и фото записываются в репозиторий. GitHub Pages публикует сайт сам. VS Code и GitHub Desktop не нужны.

## Языки (RU / UA / TR / EN)

У каждого текстового поля — **4 строки**: RU, UA, TR, EN. Русский текст в другие языки не копируется.

Цены, вес, WhatsApp и Instagram — без языков (общие).

Если UA/TR/EN пустые, на сайте показывается русский.

## Токен

Fine-grained PAT с правом Contents: Read and write.  
По умолчанию хранится в **sessionStorage**. Галочка «Запомнить этот компьютер» кладёт его в localStorage — только на своём устройстве.
