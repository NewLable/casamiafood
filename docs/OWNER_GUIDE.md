# Инструкция владельца Casa Mia

Это руководство **без программирования**. Сайт обновляется из браузера кнопкой **Сохранить изменения**.

Полная справка также встроена в админку: вкладка **📖 Помощь владельцу**.

Красивая HTML-версия: [owner-guide.html](../owner-guide.html)

---

## 1. Первый запуск

1. Откройте `https://casamiafood.vip/admin.html` (сохраните в закладки — в меню сайта ссылки нет).
2. Введите пароль админки.
3. Один раз откройте вкладку **Настройки GitHub**.
4. Заполните:
   - GitHub Username (например `NewLable`)
   - Repository Name (`casamiafood`)
   - Branch (`main`)
   - Fine-grained Personal Access Token
5. На чужом компьютере **не** ставьте «Запомнить этот компьютер».
6. Нажмите **Сохранить подключение**. Должно появиться: ✅ Подключено.

### Как получить токен

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.

- Repository access: только `casamiafood`
- Permissions → Contents: **Read and write**

Токен показывается один раз — сохраните его в надёжном месте. В код сайта он не записывается.

## 2. Как изменить цену

1. Вкладка **Цены**.
2. Впишите новую сумму.
3. Нажмите зелёную кнопку внизу **💾 Сохранить изменения**.
4. Дождитесь плашки «Изменения опубликованы на сайте».
5. Через 20–60 секунд обновите витрину.

---

## 3. Как добавить товар

1. Вкладка **Товары** → **+ Новый товар**.
2. Загрузите фото (перетащите или выберите файл).
3. Заполните название на RU / UA / TR / EN.
4. Укажите цену, вес и категорию.
5. Нажмите **Сохранить изменения**.

Фото само уменьшится до 1200 px и сохранится как WebP.

---

## 4. Как удалить товар

1. Откройте карточку товара.
2. **Удалить товар** → подтвердите.
3. Обязательно нажмите **Сохранить изменения**.

Пока кнопка внизу серая — на сайте ничего не изменилось.

---

## 5. Как изменить доставку

Вкладка **Настройки сайта** → блок **Доставка**.

Заголовок, описание, районы, стоимость, время и оплата — каждое поле на четырёх языках.

---

## 6. Как изменить текст «О нас»

Вкладка **Настройки сайта** → блок **О нас**.

Заголовок и описание на RU / UA / TR / EN. Русский текст в другие языки сам не копируется.

---

## 7. Как заменить фотографию

1. Откройте товар.
2. **Заменить** или перетащите новое фото.
3. **Сохранить изменения**.

---

## 8. Как переключить язык

На сайте в шапке: **RU · UA · TR · EN**. Выбор запоминается в браузере гостя.

---

## 9. Если перевод пустой

Посетитель увидит **русский** текст. Это нормально. Когда будет время — допишите UA, TR и EN.

---

## 10. Что происходит после «Сохранить»

1. Админка записывает JSON и фото в GitHub.
2. Создаётся commit с датой, например: `Update Casa Mia content — 2026-09-10 21:45`.
3. GitHub Pages сам публикует сайт.
4. Вы видите: ✅ Изменения опубликованы на сайте.

VS Code, GitHub Desktop и ручные commit не нужны.

## 11. Как пользоваться корзиной

Гость собирает блюда на сайте и отправляет готовый текст вам в WhatsApp или Instagram. Оплаты на сайте нет.

### Как изменить бесплатную доставку

1. Админка → вкладка **Корзина**.
2. Поле **Бесплатная доставка от** — сумма в лирах, например 800.
3. **Сохранить изменения**.

На сайте появится полоска: сколько ещё осталось до бесплатной доставки. Если поле пустое — полоска не показывается.

Минимальную сумму доставки задайте рядом, в поле **Минимальная сумма доставки**.

### Как изменить шаблон сообщения WhatsApp

1. Вкладка **Корзина**.
2. Блок **Шаблон сообщения**.
3. **Приветствие** — первая фраза (на четырёх языках).
4. **Поля в конце сообщения** — строки вроде «Имя», «Район», «Время».
5. Список блюд и итоговая сумма подставляются сами — их менять не нужно.
6. **Сохранить изменения**.

### Как изменить телефон WhatsApp

1. Вкладка **Корзина** → **Телефон WhatsApp для заказов**.
2. Или вкладка **Настройки сайта** → Контакты → WhatsApp, если поле в корзине пустое.
3. **Сохранить изменения**.

Instagram username меняется в том же блоке корзины.

### Как изменить единицы товара (упаковка / кг / штуки)

1. Вкладка **Товары** → откройте карточку.
2. **Тип количества**:
   - Упаковка — шаг 1 (пельмени в пачке, суп, тирамису).
   - Штуки — шаг 1.
   - Килограммы — шаг 0.5 (фарш, пельмени на вес).
   - Граммы — шаг 100.
3. При смене типа шаг, минимум и подпись единицы заполнятся сами. Их можно поправить вручную.
4. **Сохранить изменения**.

### Как скрыть товар, если закончился

1. Откройте товар.
2. Снимите галочку **В наличии** — на сайте появится «Нет в наличии».
3. Или включите **Скрыт** — товар исчезнет из меню.
4. **Сохранить изменения**.

Товар из корзины гостя сам не удаляется: он увидит предупреждение и сможет написать вам.

## Если сайт не обновился

- Подождите минуту и обновите страницу.
- Проверьте, что GitHub подключён (зелёный статус).
- Вкладка GitHub → «Последние публикации» — там должно быть свежее сообщение.
- Если токен истёк — вставьте новый.
