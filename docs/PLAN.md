# Casa Mia — план версии 1.0

**Домен:** [casamiafood.vip](https://casamiafood.vip)  
**Цель:** лендинг + каталог + страницы товаров + простая админка без сервера, публикация через GitHub Pages.  
**Приоритет:** мобильный вид (Instagram / WhatsApp).

---

## 1. Что строим в v1.0

| Блок | Содержание |
|------|------------|
| Публичный сайт | Главная, меню/каталог, страница товара, о нас, как готовить, доставка, отзывы, контакты |
| Данные | `data/products.json`, `categories.json`, `settings.json` |
| Админка | Логин, CRUD товаров, категории, цены, фото, бейджи, доставка/контакты |
| i18n | RU / UA / TR / EN |
| QR | Ссылки вида `/product.html?id=ravioli_chicken` |
| Документация | Этот план + README + гайд по админке и публикации |

**Не в v1.0:** корзина, онлайн-оплата, личный кабинет клиента, CMS на сервере, автоматический деплой из админки в GitHub (кнопка «Опубликовать» = инструкция + ручной/полуавтоматический push).

## 2. Стек и структура

Статический сайт (HTML / CSS / JS), без бэкенда.

```
casamiafood/
├── index.html
├── menu.html
├── product.html
├── contacts.html
├── admin.html
├── css/
│   ├── style.css
│   └── admin.css
├── js/
│   ├── app.js          # i18n, настройки, общие UI
│   ├── menu.js         # каталог, фильтры
│   ├── product.js      # карточка товара / QR
│   └── admin.js        # админка + экспорт JSON
├── data/
│   ├── products.json
│   ├── categories.json
│   └── settings.json
├── images/
│   ├── products/
│   ├── hero/
│   └── brand/
├── docs/
│   ├── PLAN.md
│   ├── ADMIN.md
│   └── DEPLOY.md
└── README.md
```

**Публикация:** GitHub Pages → DNS `casamiafood.vip`.

**Админка «без сервера»:** формы правят JSON в браузере → скачать обновлённые файлы / копировать → закоммитить в репозиторий. Пароль — простой клиентский (защита «от случайных глаз», не от хакеров).

## 3. Дизайн (по макету и этикеткам)

- **Цвета:** кремовый фон, терракота, олива, золотой акцент, тёмный текст  
- **Шрифты:** Cormorant Garamond (заголовки), Manrope (текст), рукописный акцент sparingly  
- **Настроение:** домашняя кухня, большие фото, воздух, лёгкие анимации  
- **Референсы:** макет лендинга + этикетки Casa Mia (логотип «домик + сердце», стиль фото)

Исключение из общих AI-дизайн-ограничений: бренд уже зафиксирован этикетками и ТЗ — палитра cream / terracotta / olive сохраняется.

## 5. Что нужно от вас (заказчик)

Без этих данных сайт можно сверстать на заглушках, но для запуска нужны реальные материалы.

### Сразу (блокирует контент)
1. **WhatsApp** — полный номер в формате `+90…` для кнопок и deep-link.
2. **Instagram** — точный username (`@casamia.antalya` или актуальный).
3. **Логотип** — SVG/PNG (желательно прозрачный фон); можно вырезать с этикеток.
4. **Фото товаров** — по 1–3 на позицию (этикетки + готовое блюдо / сырьё, если есть).
5. **Hero-фото** — большое аппетитное (равиоли / стол / процесс).
6. **Актуальный прайс** — финальные названия, веса, цены, категории, хиты.
7. **Пароль админки** — простой пароль только для вас (не публиковать в чатах).

### Желательно до запуска
8. Тексты «О нас» на всех 4 языках (или черновик на RU — переведём/адаптируем).
9. Список районов доставки + минимальная сумма (если уже есть).
10. 3–5 отзывов (текст или скрины Instagram).
11. Инструкции «как готовить» по категориям (если отличаются от примеров в ТЗ).
12. Фото процесса / кухни для блока «О нас» и галереи.

### Инфраструктура (с вашей стороны)
13. Репозиторий на GitHub (создать или дать доступ) — для Pages.
14. DNS у регистратора `casamiafood.vip`: записи по инструкции из `docs/DEPLOY.md` (когда будет готово).
15. После правок в админке: загрузка обновлённых JSON/фото в репозиторий (или вы присылаете файлы — я помогу закоммитить).

### Можно позже
- Стоимость доставки по районам  
- Карта Google/Yandex  
- Скрины отзывов  
- Отдельные фото для QR-страниц

## 6. Модель данных (черновик)

### `products.json` (элемент)
```json
{
  "id": "ravioli_chicken",
  "categoryId": "ravioli",
  "name": { "ru": "Равиоли куриные", "ua": "", "tr": "", "en": "" },
  "description": { "ru": "Куриное филе • сливочный вкус • ручная лепка", "ua": "", "tr": "", "en": "" },
  "ingredients": { "ru": "…", "ua": "", "tr": "", "en": "" },
  "cook": { "ru": "5–6 минут…", "ua": "", "tr": "", "en": "" },
  "serveWith": { "ru": "", "ua": "", "tr": "", "en": "" },
  "price": 230,
  "currency": "TRY",
  "weight": 500,
  "weightUnit": "g",
  "images": ["/images/products/ravioli-chicken.jpg"],
  "badges": { "hit": true, "new": false, "sale": false },
  "available": true,
  "order": 10
}
```

### `categories.json`
```json
{
  "id": "ravioli",
  "emoji": "🍝",
  "name": { "ru": "Равиоли", "ua": "", "tr": "", "en": "" },
  "order": 2
}
```

### `settings.json`
Контакты, часы, районы, минимальный заказ, ссылки соцсетей, тексты блоков, пароль админки (хэш).
